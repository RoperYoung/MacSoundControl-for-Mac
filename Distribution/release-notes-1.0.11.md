# Mac Sound Control 1.0.11

- 菜单栏面板调整为更紧凑的 354 pt 宽度，应用 Logo 放大，名称与音量条靠近，应用之间增加留白。
- 优化分应用音量拖动：连续提交最新音量，减少拖动时的整页刷新。
- “统一控制 / 分开控制”统一使用橙色主题，主窗口显示正式应用 Logo。
- 修复偏好设置关闭按钮点击区域与首次点击响应，支持 Esc 和 ⌘W 关闭。
- 补齐 ⌘Q、⌘W、⌘,、⌘H、⌘M 等常用 Mac 快捷键。
- 修复菜单滚动后多个选项悬停高亮残留。

支持 macOS 14+、Apple Silicon 与 Intel；分应用音量需要 macOS 15+。
1.0.10 用户可在“偏好设置 → 检查更新”升级。更旧版本若提示无法检查更新，请下载 DMG 手动覆盖安装一次，原有设置会保留。

## English

- A compact 354 pt menu with larger app icons, tighter label/slider grouping, and clearer spacing between apps.
- More responsive per-app volume dragging with continuous latest-value delivery and fewer full-interface refreshes.
- Consistent orange mode controls and the official app logo in the main window.
- More reliable Preferences close button, plus Escape and Command-W support.
- Standard Mac shortcuts and a fix for lingering hover highlights while scrolling the menu.

Requires macOS 14 or later; per-app volume requires macOS 15 or later. Universal for Apple Silicon and Intel Macs.
